
# CommBank Complaints Dashboard

🔗 **Live demo:** https://linhm2609-ux.github.io/commbank-complaints-dashboard/

Interactive dashboard analysing 467 customer complaints (Aug 2011 – Dec 2020)- Built with AI assistance.
Every filter and chart click cross-filters all panels and recomputes the KPIs live.

## Features
- Filters: Product, Issue, Company response
- 6 KPI cards, request-type chart, complaint trend (quarter / month), state map, annual breakdown
- Responsive layout (desktop and mobile) and keyboard-accessible charts

## KPIs
| KPI | Definition |
|---|---|
| Total complaints | Records matching current filters |
| Timely response rate | Timely response = Yes ÷ all in view |
| Consumer disputed rate | Consumer disputed = Yes ÷ all in view |
| Relief rate (closed) | Closed with monetary or non-monetary relief ÷ closed complaints |
| In progress | Records with Status = In progress |
| Top issue | Most frequent issue in view |

## Assumptions
- "Request type" is read as the channel through which the complaint was received.
- 2011 and 2020 are partial years (data starts 26 Aug 2011, ends 7 Dec 2020).
- State map uses simplified outlines; the ACT is shown as a call-out circle.
